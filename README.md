# KOSDAQ150 매수 신호 스캐너

코스닥150 구성종목을 대상으로 **"15% 이상 상승한 양봉 이후, +3%~-5% 범위의 눌림목 캔들이 2~3거래일 이어진 종목"**을 매수 후보로 찾아주는 신호 탐지 프로그램입니다.

> ⚠️ **이 프로그램은 신호 탐지(스크리닝)까지만 수행합니다.** 실제 주문을 자동으로 내는 자동매매(증권사 API 연동/실거래 체결)는 포함되어 있지 않습니다. 실거래 자동화는 자금 손실 위험이 크므로, 아래 [자동매매로 확장하기](#자동매매로-확장하기) 절을 참고해 충분히 검증한 뒤 신중하게 진행하세요.

## 패턴 정의

1. **급등 캔들**: 전일 종가 대비 종가 등락률이 `+15% 이상`이고, 양봉(종가 > 시가)인 날.
2. **눌림목(조정) 캔들**: 급등 이후 이어지는 거래일들의 전일 종가 대비 등락률이 `-5% ~ +3%` 범위 안에 있는 날.
3. 이 눌림목 구간이 **연속 2거래일 또는 3거래일** 이어지면, 그 시점에 매수 신호가 발생합니다.

임계값은 모두 [`kosdaq150_signal/config.py`](kosdaq150_signal/config.py)의 `ScanConfig`에서 조정할 수 있습니다 (급등 최소 상승률, 눌림목 범위, 눌림목 지속 일수 등).

### 실시간 스캔과 백테스트가 동일한 로직을 공유합니다

`latest_signal()`(실시간용)과 `find_signals()`(백테스트용)은 내부적으로 같은 판정 함수를 사용합니다 — "오늘"을 기준으로 **과거 방향으로만** 눌림목 연속 일수를 세고, 그 앞에 급등 캔들이 있는지 확인하는 방식입니다. 미래 데이터를 미리 알고 있다고 가정하지 않으므로, 백테스트 결과는 "그 날짜에 실시간으로 스캔했다면 나왔을 신호"와 정확히 일치합니다.

즉, 눌림목이 4거래일 이상으로 길어지면 그 4일째 시점에는 더 이상 신호가 나오지 않지만(이미 2~3일 범위를 벗어났으므로), 앞서 2일째·3일째에 이미 발생했던 신호 자체는 취소되지 않습니다 — 실제로 그 시점엔 이미 매수 판단이 끝났을 것이기 때문입니다.

## 사용법

### 1) 실시간 스캔 (매일 장 마감 후 실행)

오늘 날짜 기준으로 코스닥150 전 종목을 스캔해서, 오늘이 "급등 후 2~3일째 눌림목"에 해당하는 종목을 찾습니다.

```bash
python -m kosdaq150_signal.scanner live --out signals_today.csv
```

### 2) 백테스트 (과거 특정 기간 전수 조사)

```bash
python -m kosdaq150_signal.scanner backtest --from 20250101 --to 20260820 --out signals_backtest.csv
```

### 파이썬 코드에서 직접 사용

```python
from datetime import date
from kosdaq150_signal.config import ScanConfig
from kosdaq150_signal.data_fetcher import get_kosdaq150_tickers, get_ohlcv
from kosdaq150_signal.signal import latest_signal

cfg = ScanConfig(surge_min_pct=15.0, pullback_min_pct=-5.0, pullback_max_pct=3.0)

for ticker, name in get_kosdaq150_tickers():
    df = get_ohlcv(ticker, date(2026, 6, 1), date.today())
    sig = latest_signal(df, ticker, name, cfg)
    if sig:
        print(name, sig.as_dict())
```

## 해석상 선택한 기준 (참고)

요청하신 조건에서 모호할 수 있는 부분은 다음과 같이 구체화했습니다. `config.py`에서 바로 바꿀 수 있습니다.

- **"15% 이상 상승"** = 전일 종가 대비 당일 **종가** 등락률 기준 (장중 고가 기준 아님).
- **"양봉"** = 종가가 시가보다 높은 날.
- **"+3~-5%의 봉"** = 전일 종가 대비 당일 종가 등락률이 `-5% ≤ 등락률 ≤ +3%`인 날.
- **"2~3거래일"** = 급등 다음날부터 조정 캔들이 연속으로 2일 또는 3일 지속된 시점에 신호 발생 (위 실시간/백테스트 동일 로직 설명 참고).

## 자동매매로 확장하기

실제 매수 주문까지 자동화하려면 증권사 Open API(예: 한국투자증권 KIS Developers, 키움 OpenAPI+ 등)를 연동해야 합니다. 이 저장소는 신호 생성까지만 다루며, 아래 사항은 반드시 직접 검토하시길 권합니다:

- **모의투자(paper trading) 계좌로 충분히 검증** 후 실계좌 적용
- 매수 후 손절/익절 기준, 포지션 사이징, 1일 최대 매수 종목 수 등 **리스크 관리 규칙**을 별도로 설계
- API 호출 빈도 제한, 인증 토큰 관리, 주문 체결 확인/재시도 로직
- 이 패턴 하나만으로는 백테스트 샘플이 충분치 않을 수 있으므로, 장기간 데이터로 승률/손익비를 먼저 검증

이 코드는 투자 조언이 아니며, 실거래로 인한 손실에 대해 어떠한 책임도 지지 않습니다.
